# LeadFesta — demonstração independente

Esta pasta contém uma demonstração navegável do módulo LeadFesta.

- A demonstração usa somente dados fictícios.
- Os cadastros e atividades são guardados no armazenamento local do navegador (localStorage).
- Nenhuma informação é enviada ao Supabase ou ao sistema de produção.
- Limpar os dados do site/navegador apaga os dados de teste.
- O acesso será publicado em `/kidsloc-app/leadfesta/`, ao lado do site KidsLoc existente.

Esta demonstração serve para avaliar o fluxo e a interface. Ela não substitui a implementação integrada que está sendo validada nas PRs #87 e #88.
